#  Projeto Git e GitHub

Repositório criado para praticar o **controle de versão** com Git, gerenciamento de repositórios remotos no GitHub e documentação utilizando **Markdown**.

> **Nota:** Um bom `README.md` funciona como o cartão de visitas de qualquer projeto de desenvolvimento.

---

##  Tecnologias Utilizadas

- **Git** — Sistema de controle de versão distribuído
- **GitHub** — Plataforma de hospedagem e colaboração de código
- **Markdown** — Linguagem de marcação leve para documentação

---

##  Como clonar e executar este projeto

1. Abra o terminal (**Git Bash** no Windows ou Terminal no Linux/macOS).
2. Clone este repositório para o seu computador:

```bash
git clone https://github.com/MariaCBrito/projeto-git.git
```

3. Acesse a pasta do projeto:

```bash
cd projeto-git
```

---

##  Principais Comandos Praticados

| Comando | Descrição |
| :--- | :--- |
| `git init` | Inicializa um novo repositório Git local |
| `git status` | Verifica o estado atual dos arquivos |
| `git add .` | Adiciona as alterações para a área de *staging* |
| `git commit -m "msg"` | Registra um novo ponto no histórico do projeto |
| `git push -u origin main` | Envia os commits locais para o GitHub |
